# MiniMax H3 提示词规范器

一个面向小白、适用范围广的 Codex Skill。无论输入是一句话、一段已有提示词、一个画面想法，还是完整故事和剧本，都能整理成可直接用于 MiniMax H3 的规范视频提示词。

## 能处理什么

- 一句话扩写成 H3 提示词
- 混乱长提示词的整理、缩减与防错
- 故事或剧本的分段生成方案
- 文戏、动作、广告、Vlog、真人实拍和二维动画
- 单图、多图、首尾帧及角色一致性引用
- 对白、口型、环境声、动作声和音乐设计

## 使用示例

```text
使用 $minimax-h3-prompt-standardizer：一个女孩在雨夜车站等人，8秒，16:9。
```

```text
使用 $minimax-h3-prompt-standardizer，把下面这段故事拆成适合 H3 分段生成的规范提示词：……
```

默认优先直接产出可复制的中文提示词；只有真正缺少会改变结果的信息时，才会提出一个简短问题。
