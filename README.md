# H3 Realistic Close-up Dialogue

一个轻量的 Codex Skill，用于把人物参考图、短对白与时长要求整理成 MiniMax H3 可直接使用的中英双语真人面部近景提示词。

## 使用示例

```text
使用 $h3-realistic-closeup-dialogue：图1作为人物参考，5秒，女孩趴在白色床单上看向镜头说“我喜欢你”，突出瞳孔、睫毛、毛孔和面部汗毛。
```

## 输出

- 中文 H3 生产 Prompt
- English H3 Production Prompt

Skill 会默认强化人物一致性、真实皮肤细节、微表情、口型同步、环境声与常见防错约束。
